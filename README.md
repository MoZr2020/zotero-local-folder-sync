Zotero 本地文件夹同步

在 Zotero 个人文库中，将一个分类绑定到本地文件夹。右键点击 **刷新本地文件夹**，即可按本地目录结构创建子分类，并把文件作为链接附件加入对应分类。

## 安装

**版本** v1.0.1 · **适用范围** Zotero 桌面版 10.0.x · **测试环境** Windows / Zotero 10.0.7

1. 下载 [zotero-local-folder-sync-1.0.1.xpi](./zotero-local-folder-sync-1.0.1.xpi)，保留 `.xpi` 文件。
2. 打开 Zotero，进入 **工具 → 插件**。
3. 点击齿轮图标，选择 **从文件安装插件…**，选中下载的 `.xpi`。

## 使用

1. 在 Zotero 左侧的个人文库中，右键点击要绑定的分类，选择 **链接本地文件夹…**。
2. 在弹出的窗口中选择本地文件夹。这个文件夹对应当前分类，它下面的目录对应各级子分类。
3. 再次右键点击该分类，选择相邻的 **刷新本地文件夹**。完成后，弹窗会显示新建分类、新增附件和已有附件的数量。
4. 后续加入新的文件或子目录后，再点一次 **刷新本地文件夹**。更换绑定目录时，重新选择 **链接本地文件夹…**。

例如，将 Zotero 的「科研资料」分类绑定到本地「科研资料」文件夹后，刷新会得到以下结构。

```text
科研资料
├─ 综述.pdf                    链接附件
└─ 实验文献                    子分类
   ├─ 实验方法.pdf             链接附件
   └─ 待整理                   子分类（空文件夹）
```

## 刷新规则

| 本地情况 | Zotero 中的处理 |
| --- | --- |
| 发现子文件夹 | 复用同一层级的同名子分类，缺少时新建。空文件夹也会创建分类。 |
| 发现普通文件 | 在对应分类添加链接附件。原件留在本地，打开附件需要能够访问原路径。 |
| 同一分类已有指向该路径的链接附件 | 计入已有附件，跳过重复添加。 |
| 文件或目录被移动、改名或删除 | 已有条目需在 Zotero 中手动整理。新路径上的文件可能作为新附件加入。 |
| 发现符号链接、目录联接或其他特殊路径 | 跳过，避免扫描到绑定目录之外或进入循环。 |

同步由右键菜单手动触发。文件以附件形式加入，作者、年份、DOI 等文献元数据可在 Zotero 中另行补充。

## 常见问题

**提示插件可能与当前版本不兼容**

在 Zotero 的 **帮助 → 关于 Zotero** 中确认版本为 10.0.x，并选择 v1.0.1 的安装包。v1.0.1 修复了初版缺少必填安装字段的问题。

**刷新按钮是灰色的**

先为该分类选择本地文件夹。菜单适用于个人文库中的单个分类。

**刷新后有失败项**

查看弹窗中列出的路径，确认文件夹存在且 Zotero 有读取权限。路径已更换时，可以重新绑定。修正后再次刷新，已成功加入的附件会按路径去重。
